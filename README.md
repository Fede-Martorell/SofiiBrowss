Plataforma web de reserva de turnos online y gestión integral de estética facial para **Sofibrowss Studio** (Luján de Cuyo, Mendoza). Diseñada con una interfaz **Luxury Glassmorphism**, animación dinámica de fondo satinado, modo claro/oscuro ambiental y panel administrativo reactivo con acceso por roles.

---

## 🌟 Características Principales

### 💎 Experiencia del Cliente (Frontend)
- **Sistema de Reservas en 3 Pasos**: Selección de fecha, horarios dinámicos en tiempo real y formulario con confirmación directa.
- **Integración con WhatsApp & Google Calendar**: Confirmación instantánea prellenada vía API de WhatsApp y botón directo para agregar recordatorios a Google Calendar con 1 clic.
- **Botón Flotante de Atención Rápida**: Chat flotante de WhatsApp siempre visible en la pantalla.
- **Modo Claro / Oscuro Satinado**: Paleta entibiada estilo *Night Light* (`#f4ebd9` y café espresso) para evitar la fatiga visual.
- **Reseñas & Testimonios Verificados**: Muestra de calificaciones 5.0 ⭐ y experiencias reales de clientas atendidas.
- **Filtro Interactivo por Tratamiento**: Categorización rápida (*Pestañas*, *Cejas*, *Combos VIP*).
- **Carruseles Multi-Foto por Servicio**: Galería dinámica de fotos del *Antes & Después*.

### 👑 Panel de Administración (Dueña & Equipo)
- **Acceso por Roles con Clave Secreta**:
  - **Dueña**: Control total de precios, catálogo de servicios, fotos de galería, moderación de opiniones, horarios del local y contraseñas.
  - **Equipo**: Vista enfocada exclusivamente a consultar, confirmar o cancelar turnos agendados.
- **Moderación de Opiniones**: Aprobar o eliminar reseñas publicadas por clientas.
- **Carga Directa de Imágenes**: Soporte para seleccionar múltiples fotos desde el celular o computadora.
- **Soporte Móvil Responsive**: Menú horizontal deslizante optimizado para administración desde smartphones.

---

## 🛠️ Tecnologías Utilizadas

- **Core**: React 18, TypeScript, Vite.
- **Icons**: Lucide React.
- **Styling**: Vanilla CSS (Variables CSS dinámicas, Glassmorphism, Mesh Gradient Animations).
- **Persistencia**: LocalStorage (Fallback local para configuraciones, turnos, catálogo y reseñas).

---

## 🚀 Instalación y Ejecución Local

1. **Clonar el repositorio:**
   ```bash
   git clone https://github.com/Fede-Martorell/SofiBrownss.git
   cd SofiBrownss
   ```

2. **Instalar dependencias:**
   ```bash
   npm install
   ```

3. **Ejecutar servidor de desarrollo:**
   ```bash
   npm run dev
   ```

4. **Compilar para producción:**
   ```bash
   npm run build
   ```
